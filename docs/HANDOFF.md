# FIC 2.0: передача контекста

Этот файл хранит текущее состояние работы между чатами. Он не является журналом
всей разработки и не заменяет `AGENTS.md` или архитектурную документацию.
Следующий агент должен сначала прочитать этот файл, затем проверить фактическое
состояние через `git status`.

## Текущий снимок

- Обновлено: 2026-06-28.
- Ветка: `main`.
- Базовый commit: `a4d1130`.
- Текущая задача: улучшить читаемость вкладки контроля устройств в `fic-gui`,
  где длинные названия узлов, `devpath` и значения параметров скрывались за
  многоточием или уходили за границы видимой области.

## Сделано

- В `DeviceTree` отключено elide-поведение для текста узлов дерева:
  длинные имена больше не превращаются в `...`.
- Для виртуальных и fallback-узлов дерева полный sysfs `devpath` заменен в
  подписи на короткий хвост пути; полный путь сохранен в tooltip и параметрах
  устройства.
- Уменьшен отступ уровней дерева, чтобы глубокие PCI/USB/block-ветки занимали
  меньше горизонтального места.
- Дерево устройств получило большую минимальную ширину, а колонка имени
  устройства расширяется после загрузки корня и после ленивой загрузки дочерних
  узлов.
- Колонка `Контроль` немного расширена, чтобы статусы управления меньше
  сжимали первую колонку.
- Для узлов дерева добавлена подсказка с полным названием устройства; для
  исторических/неактуальных устройств в подсказке сохранена диагностика
  `boot_id`.
- Основной layout вкладки контроля устройств теперь отдает дереву устройств
  большую часть свободной ширины, а не фиксирует левую панель на узком размере.
- Верхнее поле `devpath` переносится по строкам и, как остальные поля
  устройства, показывает полное значение в tooltip.
- Таблица параметров устройства справа больше не обрезает значения через `...`;
  для длинных значений включена горизонтальная прокрутка и tooltip.

## Риски и что проверить в runtime

- На деревьях с очень длинными sysfs/devpath-подписями ожидается горизонтальная
  прокрутка; нужно визуально проверить, что ширина дерева комфортна на целевых
  разрешениях.
- Нужно проверить, что правая панель параметров устройств остается достаточно
  широкой на минимальном поддерживаемом размере окна.
