## Известное состояние и ограничения

- CMake конфигурируется успешно, но выводит deprecation warnings из-за
  `cmake_minimum_required(VERSION 3.5)` во всех CMake-проектах.
- Политики и runtime-интеграция рассчитаны на Linux и системные пути
  `/opt/fic`, `/run/fic`, systemd, udev и графические окружения. Полноценная
  интеграционная проверка может изменить ОС и должна выполняться осознанно.
- Группа `fic` предоставляет полный административный доступ к daemon API.
- `fic-session-agent` необходим для политик, которым нужен контекст
  графической пользовательской сессии.
- Последние изменения в истории касались ALT p11 packaging, безопасного запуска
  внешних команд и путей к хэшам команд. Это контекст недавней работы, но не
  зафиксированный список открытых задач.

Если документы будут приняты, следующий естественный шаг — закоммитить

## Как продолжать в новой сессии

1. Прочитать `AGENTS.md` и этот файл.
2. Выполнить `git status --short` и сверить ветку/HEAD с этим снимком.
3. Для новой задачи открыть только соответствующий README и нужный раздел
   `docs/architecture-diagrams.md`.
4. После работы заменить текущие секции `Сделано`, `Измененные файлы`,
   `Проверки`, `Что осталось` и обновить дату/commit.

Не накапливай здесь подробную хронику: Git уже хранит историю. Оставляй только
информацию, без которой следующая сессия рискует повторить исследование,
сломать инвариант или потерять незавершенную работу.
