## Сделано

  `[tab:DEVICES]` и `[tab:LOG]`.
- Динамические вкладки, полученные из `policy_list`, единообразно используют
  ключ `[module:<имя>]`.
- Заголовок модуля `DC` изменен на «Настройки контроля устройств» /
  `Device control settings`.
- Удалены больше не нужные ключи `[module:LOG]` и
  `[module:DC][settings]`, а также специальная ветка выбора заголовка для `DC`
  в GUI.

## Риски и решения

- Пространство ключей отражает источник структуры экрана, а не источник данных
  локализации: и `[tab:*]`, и `[module:*]` по-прежнему приходят в GUI через
  общий `localization_bundle` daemon API.
- Для новых встроенных экранов GUI следует использовать `[tab:*]`; для вкладок,
  сформированных из policy-модулей, — `[module:*]`.
