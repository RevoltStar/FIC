# FIC 2.0: передача контекста

Этот файл хранит текущее состояние работы между чатами. Он не является журналом
всей разработки и не заменяет `AGENTS.md` или архитектурную документацию.

## Текущий снимок

- Обновлено: 2026-07-12.
- Ветка: `main`.
- Базовый commit: `95ee80a`.
- Текущая задача: локализовать диагностические сообщения `Ssh::apply()` через
  `LocalizationManager`.

## Сделано

- Все восемь диагностических сообщений `Ssh::apply()` заменены вызовами
  `LocalizationManager::getLang()`.
- Сообщения с именем политики, SSH-параметром и текущим/ожидаемым значением
  собираются прямой конкатенацией динамических значений с локализованными
  фрагментами, без отдельного форматтера.
- В `en.lang` и `ru.lang` добавлены соответствующие ключи пространства
  `[module:NET][submodule:SshEdit][message:...]`.
- Служебный маркер `[NO VALUE SET]` намеренно не локализован: это значение
  конфигурационного протокола, а не пользовательское сообщение.

## Измененные файлы

- `fic/src/modules/net/submodules/Ssh.cpp`
- `fic/src/scripts/lang/en.lang`
- `fic/src/scripts/lang/ru.lang`
- `docs/HANDOFF.md`

## Проверки

Выполнено успешно:

```bash
cmake -S . -B /tmp/fic2-build-check
cmake --build /tmp/fic2-build-check --target fic -j2
git diff --check
```

Исходный `build-check` использовать не удалось: его CMake-кэш содержит путь с
другим регистром (`/mnt/c/users/...`), и sandbox отклонил запись как выход за
разрешенный workspace. Поэтому выполнена чистая конфигурация в `/tmp`.

Runtime-проверка `Ssh::apply()` не запускалась, поскольку она может изменить
`/etc/ssh/sshd_config`.

## Что осталось и риски

- Автоматизированных unit/CTest-тестов для подстановки шаблонов и переключения
  языка в проекте нет.
- `MultilineConfigFileHandler` обрезает крайние пробелы значений, поэтому
  границы локализованных фрагментов сделаны по кавычкам и пунктуации, а не по
  пробелам.
- Разбиение сообщений на фрагменты подходит для текущих русского и английского
  переводов, но язык с другим порядком динамических частей может потребовать
  общего механизма форматирования в `LocalizationManager`.
